# KAVAO — экономика шоколада

Грубый калькулятор для маленькой bean-to-bar шоколадной при кафе: сколько шоколад зарабатывает за неделю и какой меланжёр брать — 7, 25 или 35 кг.

Сайт: https://cyrilvdt.github.io/kavao-renovace/

## Локально

```bash
npm install
npm run dev    # http://localhost:5176
npm test
```

## Обновить сайт

```bash
npm run deploy
```

Собирает `dist/` и выкладывает его в ветку `gh-pages`, откуда GitHub Pages показывает сайт.
